# Hardest Tower Defence — legal and support pages

The privacy policy and support pages of the iOS game Hardest Tower Defence (App Store Connect app 6828239608),
served by GitHub Pages at https://tyfoan.github.io/hardest-tower-defence-legal/.

- `privacy.html` — the privacy policy (App Store Connect: Privacy Policy URL; AdMob consent message).
- `support.html` — support, restoring purchases, subscriptions (App Store Connect: Support URL).

Plain HTML, no build step. When the game's data handling changes, update `privacy.html` and its date.
